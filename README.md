🍽️ Recipe Finder App

Abstract
The Recipe Finder App is a full-stack web app that helps users find recipes based on their available ingredients. By using HTML, CSS, JavaScript, Python, and the Spoonacular API, the web app provides a variety of recipes as well as links to each of the recipe’s homepage, where users can get the detailed steps on how to make the recipe. This report highlights our main objectives and approach to developing this web app.

📌 Features

Search for recipes by entering ingredients

Retrieves real-time data from the Spoonacular API

Displays recipe names, images, and direct links to full instructions

Simple, user-friendly interface

Full-stack implementation using frontend and backend code


🛠️ Technologies Used

HTML / CSS

JavaScript

Python

Spoonacular API


🚀 How to Use
- Input your ingredients into the search bar and press "Search"
 
- See the list of recipes and select whichever one you like
 
- Click on the recipe and click its associated link to get taken to the recipe homepage
